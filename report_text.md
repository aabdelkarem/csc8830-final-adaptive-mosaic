# Adaptive Mosaic Art

Problem. A regular mosaic assigns the same tile size to flat backgrounds and detailed objects. This wastes a limited tile budget on smooth regions and removes structure from faces, curves and texture. Adaptive Mosaic Art explores a computer-vision approach to creating geometric artwork from a photograph. The objective is to preserve more of the source image at a fixed number of color regions while allowing a reduced palette and dark tile outlines as artistic controls. This is a newly prepared project direction; prior instructor approval is not claimed.

Approach. The input is oriented, center cropped and resized to 256 by 256 pixels. Integral images of RGB values and their squares give each rectangular region its mean color and squared reconstruction error. A greedy quadtree algorithm repeatedly selects the available four-way split with the largest reduction in total squared error. The baseline uses an equally sized regular grid with exactly the same number of tiles. The art layer quantizes tile means to six levels per channel and draws dark borders. An offline HTML demo supports included images and local photographs, while a Python implementation reproduces the evaluation.

Results. Nine actual comparisons were run on three openly reusable photographs at 64, 256 and 1,024 tiles. Adaptive partitioning achieved lower unquantized RGB mean squared error than the matching uniform grid in all nine comparisons. At 256 tiles, the reductions were astronaut: 14.96%, coffee: 19.94%, chelsea: 14.29%. Coverage, tile-count, monotonic-error, constant-image and quadrant-image checks passed. The JavaScript core reproduced the Python astronaut result at 256 tiles. These measurements evaluate color fidelity before the artistic layer; they do not establish aesthetic preference or general performance beyond these three photographs.
