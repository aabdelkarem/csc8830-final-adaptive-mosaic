# Image attribution

The original images in `assets/` were copied from the installed scikit-image data directory. No image was represented as Aya's own photograph.

| File | Credit | License description in source documentation |
|---|---|---|
| astronaut.png | NASA photograph of Eileen Collins | Public domain; no known copyright restrictions |
| coffee.png | Rachel Michetti, courtesy of Pikolo Espresso Bar | CC0 |
| chelsea.png | Stefan van der Walt | CC0 |

Source: https://scikit-image.org/docs/stable/api/skimage.data.html (accessed 18 November 2026).

Evaluation crops are generated by orienting, center cropping and resizing to 256 by 256 pixels using Pillow LANCZOS. Both evaluated algorithms use identical crops. The browser uses these already-preprocessed embedded crops for its sample images. Browser resizing of a custom photograph may differ from Pillow's resizing.

The method is a straightforward greedy quadtree color approximation. No claim of a new research algorithm or semantic image understanding is made.
